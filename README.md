## Задание 1 (3)

- `const auto Pi = std::acos(0) * 2;` — обычный константный объект. Значение нельзя менять через `Pi`, но это не гарантирует вычисление на этапе компиляции.
- `constexpr auto Pi = std::acos(0) * 2;` — требует, чтобы выражение было допустимым константным выражением. В стандартных версиях C++, где `std::acos` не является `constexpr`, такой вариант не компилируется.
- `const auto Pi = std::acos(x) * 2;` — компилируется, но значение зависит от переменной `x`. Это не константа этапа трансляции.
- `constexpr auto Pi = std::acos(x) * 2;` — не компилируется: `x` — обычная переменная, а выражение с ней не является константным выражением. Даже если библиотека поддерживает `constexpr` для `acos`, это не делает переменную `x` константой времени компиляции.

## Задание 3 (2)

Результат программы — **18**.

Во внешнем цикле создаётся `i`, который последовательно принимает значения `0...3`. Внутренний цикл объявляет собственную переменную `i`, она скрывает внешнюю только внутри внутреннего цикла и принимает значения `0...2`. Поэтому за один проход внутренний цикл прибавляет `0 + 1 + 2 = 3`. За четыре прохода это `3 * 4 = 12`.

После завершения внутреннего цикла снова доступна внешняя `i`. Команда `s += i` добавляет `0 + 1 + 2 + 3 = 6`. Итог: `12 + 6 = 18`. Область видимости внутренней переменной заканчивается вместе с внутренним циклом.

## Задание 4 (2)

Результат программы — **20**.

В Python цикл не создаёт отдельную область видимости для переменной, объявленной в заголовке `for`. Внутренний цикл перезаписывает `i` значениями `0...2`. После него `i` остаётся равной `2`, поэтому команда `s += i` каждый раз добавляет `2`.

За каждый из четырёх проходов прибавляется `0 + 1 + 2 + 2 = 5`. Всего `5 * 4 = 20`. При этом внешний цикл продолжает четыре итерации: его итератор хранит последовательность `range(4)` независимо от текущего значения имени `i`.

в C++ переменная внутреннего цикла имеет собственную область видимости и не изменяет внешнюю `i`. В Python имя `i` после внутреннего цикла остаётся связанным с последним значением — `2`.

## Задание 5 (2)

```cpp
#include <iostream>

namespace first {
    int value = 10;
    void print() {
        std::cout << "first: " << value << '\n';
    }
}

namespace second {
    int value = 25;
    void print() {
        std::cout << "second: " << value << '\n';
    }
}

int main() {
    first::print();
    second::print();

    std::cout << first::value + second::value << '\n';

    return 0;
}
```

Вывод:

```
first: 10
second: 25
35
```

Одинаковые имена `value` и `print` не конфликтуют, потому что находятся в разных пространствах имён. Полное имя включает пространство имён и имя объекта.

## Задание 6 (2)

В каждой итерации создаётся копия `c(a)`, а затем содержимое строк копируется при присваиваниях.

### Медленный вариант

```cpp
#include <iostream>
#include <string>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::string c(a);
        a = b;
        b = c;
    }

    std::cout << a[0] << b[0] << '\n';

    return 0;
}
```

Команда `time` показала, что программа работала минуту.

### Быстрый вариант с временной переменной


```cpp
#include <iostream>
#include <string>
#include <utility>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        std::string c(std::move(a));
        a = std::move(b);
        b = std::move(c);
    }

    std::cout << a[0] << b[0] << '\n';

    return 0;
}
```

`std::move` позволяет использовать семантику перемещения вместо копирования. Команда показала время работы `0.05` секунд.

## Задание 7 (2)

При первом присваивании создаётся строковый объект `'Hello world'`, а имя `a` ссылается на него. После `b = a` оба имени ссылаются на один объект, поэтому первые два вызова `id` показывают одинаковое значение.

Строки в Python неизменяемы. Выражение `a += ' and goodbye'` создаёт новую строку с объединённым содержимым и связывает имя `a` с новым объектом. Имя `b` по-прежнему указывает на старую строку `'Hello world'`. Поэтому последние две строки вывода показывают разное содержимое и разные значения `id`.

`id()` возвращает идентификатор объекта, который уникален среди одновременно существующих объектов.

## Задание 8 (2)

```Python
a = "Hello world"
b = a
c = a[:]

print("a:", a, id(a))
print("b = a:", b, id(b))
print("c = a[:]:", c, id(c))

print("a и b — один объект:", a is b)
print("a и c — один объект:", a is c)
```

В обоих случаях переменные содержат одинаковую строку. Присваивание `b = a` связывает `b` с тем же объектом, что и `a`. Выражение `a[:]` создаёт срез всей строки, однако Python может вернуть тот же объект. Поэтому в CPython `a is c` также может быть `True`. Строки неизменяемы, поэтому менять их содержимое через одну из переменных нельзя.
