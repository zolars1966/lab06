# Языки программирования
## Лабораторная работа 6

## Задание 1 (3)

- `const auto Pi = std::acos(0) * 2;` — обычный константный объект. Значение нельзя менять через `Pi`, но это не гарантирует вычисление на этапе компиляции.
- `constexpr auto Pi = std::acos(0) * 2;` — требует, чтобы выражение было допустимым константным выражением. В стандартных версиях C++, где `std::acos` не является `constexpr`, такой вариант не компилируется.
- `const auto Pi = std::acos(x) * 2;` — компилируется, но значение зависит от переменной `x`. Это не константа этапа трансляции.
- `constexpr auto Pi = std::acos(x) * 2;` — не компилируется: `x` — обычная переменная, а выражение с ней не является константным выражением. Даже если библиотека поддерживает `constexpr` для `acos`, это не делает переменную `x` константой времени компиляции.

## Задание 2 (2)

Вложенные блоки нужны, потому что в каждом блоке объявлены переменные с одинаковыми именами `x` и `y`, но разных типов. Объявить две переменные с одинаковым именем в одной и той же области видимости нельзя.

Скобки создают отдельные области видимости: после выхода из первого блока его `x` и `y` перестают быть доступны, поэтому во втором блоке можно объявить новые переменные с такими же именами.
